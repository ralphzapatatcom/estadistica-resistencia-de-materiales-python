# Análisis Estadístico: Resistencia de Materiales (Aleación de Aluminio) 🏗️

Este proyecto aplica conceptos de estadística industrial y control de calidad para evaluar la seguridad de una aleación de aluminio utilizada en la construcción. El enfoque principal es la resolución de problemas mediante **Pruebas de Hipótesis** y **Distribuciones Normales** utilizando Python.

## 📋 Contexto del Problema
Una metalúrgica produce vigas cuya resistencia media debe ser de **70,000 psi** con una desviación estándar de **2,500 psi**. El objetivo es determinar:
1. La probabilidad de falla bajo un límite crítico de seguridad.
2. Si un lote nuevo debe ser rechazado mediante una prueba de hipótesis (Z-test).
3. El valor de resistencia para garantías técnicas (Percentiles).

## 🛠️ Tecnologías Utilizadas
* **Python 3.x**
* **SciPy:** Para cálculos estadísticos avanzados (`stats.norm`).
* **Math:** Para operaciones aritméticas base.
